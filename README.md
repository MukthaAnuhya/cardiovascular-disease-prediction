# Cardiovascular Disease Prediction

## Project Overview

This project uses Machine Learning to predict the possibility of cardiovascular disease based on patient-related features.

The project includes data preprocessing, exploratory data analysis, multiple machine learning models, model evaluation, and an interactive prediction interface.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Gradio
- Google Colab
- Jupyter Notebook

## Dataset Features

The model uses the following features:

- Age
- Gender
- Height
- Weight
- Systolic Blood Pressure
- Diastolic Blood Pressure
- Cholesterol
- Glucose
- Smoking
- Alcohol Intake
- Physical Activity

## Machine Learning Models

The following models were implemented and compared:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest
5. Support Vector Machine (SVM)

## Model Performance

The models were evaluated using test data.

| Model | Accuracy |
|------|----------|
| Logistic Regression | 72.27% |
| KNN | 65.33% |
| Decision Tree | 63.64% |
| Random Forest | 70.86% |
| SVM | 73.23% |

## Interactive Prediction

A Gradio-based interface was created where users can enter patient-related feature values and receive a machine-learning model prediction.
